AML Investigation Agent

An AI-assisted anti-money-laundering case manager. Transaction monitoring raises alerts, an AI agent investigates each one with read-only tools and drafts a recommendation, and analysts decide under a four-eyes rule. Every AI claim is checked against the data.

How it works

  1. Monitoring. A model scores every payment; alerts arrive with a priority and the main reasons in plain words.
  2. AI review. Opening an alert starts a LangGraph agent: code builds the case file, the agent checks history and counterparties through MCP tools, names the pattern, and cites public AML guidance.
  3. Human decision. The analyst closes, escalates or asks for more. Escalations need a different supervisor, enforced by the server.
  4. SAR draft. For a confirmed escalation, code assembles the facts and the AI writes the narrative; amounts and citations are checked before a supervisor approves.
  5. Copilot. The analyst can ask questions; answers stream with each lookup and every cited transaction is verified.

Built with

LangGraph, Model Context Protocol, Ollama (gpt-oss:20b), FastAPI, Postgres with pgvector, DuckDB, XGBoost with SHAP, React, TypeScript, Ant Design, Cytoscape.js, Docker, GitHub Actions. Design notes, evaluations and model cards are in the repository.

Synthetic data only (IBM AMLworld, CDLA-Sharing 1.0); nothing is filed with any authority and results on synthetic data do not show real-world performance.
